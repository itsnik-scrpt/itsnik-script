<br />

I bridge high-performance systems programming with intuitive, modern interface design. From low-level game modding and custom server architecture to full-stack web applications and UI/UX design systems, my work centers around building optimized tools and engaging experiences for gaming communities.

<br />

| Domain | Technical Scope | Deliverables & Focus |
| :--- | :--- | :--- |
| **Game Dev & Modding** | Java, C#, C++, Minecraft Fabric/Forge, Game Logic | Custom gameplay mechanics, server plugins, and high-performance Minecraft modpacks (e.g., *PvPPerfected* under ScriptWorld). |
| **UI/UX & Product Design** | Figma, Design Systems, UX Research, Layouts | Modern web interfaces, application design flows, and gaming dashboards engineered for visual polish and usability. |
| **Full-Stack Systems** | React, Next.js, TypeScript, Tailwind CSS, REST APIs | Modern web platforms, community management applications, and responsive frontends backed by fast APIs. |
| **Backend & Infrastructure** | Node.js, PostgreSQL, Docker, Linux Automation, Shell | Server administration scripts (`itsnik-script`), database architecture, containerized services, and automated workflow tooling. |
